# 멈춤의 정원 (Garden of Stillness)

인터랙티브미디어개발 기말 프로젝트 (2인 개발) · Processing 4 (Java 모드) + 웹캠

> **관객의 행동이 규칙에 따라 움직이는 정원을 바꾸고, 그 변화를 보여 준다.**

웹캠 앞에 서면 화면 속 잔디 평원에 내 실루엣("회색 인간")이 선다.
**가만히 있으면** 땅의 씨앗에서 싹이 트고 꽃이 피며, 꽃은 시들면서 씨앗을 남겨 다음 세대로 이어진다.
**움직이면** 바람이 일고, 움직인 자리의 꽃이 꽃잎으로 흩날려 거름이 된다.
자세는 결과를 직접 고르지 않고 **환경 값(고요함·햇빛·바람·거름)의 목표만 옮긴다.** 화면의 변화는 모두 그 값으로 계산되는 규칙의 결과다.

| 관객의 행동 | 정원의 변화 |
|---|---|
| 가만히 서 있기 | 고요함 ↑ → 꽃이 자란다 (성장 ×1), 배경 음악이 커진다 |
| 두 손 들고 멈추기 | 햇빛 ↑ → 해가 뜨고 빨리 자란다 (×2), 새소리 |
| 웅크리기 | 햇빛 ↓ → 밤, 성장이 멈추고 반딧불이·풀벌레 소리 |
| 움직이기 | 바람 → 움직인 칸의 꽃이 흩날리고, 떨어진 꽃잎은 거름이 된다 |
| 손 흔들기 | 나비가 가까운 꽃으로 날아가 꽃가루를 옮긴다 → 다음 세대 색이 섞인다 |
| 팔 벌리고 멈추기 | 땅에서 양팔 끝을 향해 덩굴이 자란다 |
| 몸 기울이기 | 기운 쪽으로 산들바람이 분다 |

## 실행

1. **Processing 4**에 라이브러리 3개를 설치한다 (`스케치 → 라이브러리 가져오기 → 라이브러리 추가`)
   - Video 2.2.2 · Minim 2.2.2 · ControlP5 2.2.6
2. [`gardenOfStillness/gardenOfStillness.pde`](gardenOfStillness/gardenOfStillness.pde)를 열고 실행한다.
3. 웹캠이 있으면: **카메라 밖으로 나간 뒤 `B`** (빈 배경 찍기) → 화면 앞에 선다.
   웹캠 없이 정원만 보려면 **`M`** (마우스판: 마우스 움직임 = 관객의 움직임).
4. 키가 안 먹으면 한/영 키를 눌러 영문 입력으로 바꾼다.

### 키

| 키 | 하는 일 |
|---|---|
| `1` `2` `3` `4` | 자세 알려 주기: 차렷 · 두손들기 · 웅크리기 · 팔벌리기 *(실루엣 판정 전까지 임시)* |
| `W` · `←` `→` (누르는 동안) | 손 흔들기(마우스 자리) · 몸 기울기 *(판정 전까지 임시)* |
| `0` (누르는 동안) | 사람 없음 (마우스판) |
| `B` · `M` | 빈 배경 찍기 · 웹캠 ↔ 마우스판 |
| `[` `]` · `-` `=` | 사람으로 볼 색 차이(`threshold`) · 고요함 기준(`calmSensitivity`) |
| `S` · `L` | 사진 저장(`photos/`) · 기록 켜고 끄기(`logs/` CSV) |
| `D` · `H` · `R` | 점검 정보 · 조절판 숨기기 · 정원 처음으로 |

## 구성

```
gardenOfStillness/
├─ gardenOfStillness.pde   메인: setup · draw 순서 · 키
├─ Vision.pde  Pose.pde  Log.pde        A 입력·측정: 웹캠 · 배경 빼기 · 칸별 움직임 · 실루엣 · 자세 · 기록
├─ Scene.pde                            B 환경 값 규칙 · 정원 매 프레임 규칙 · 하늘 · 반딧불이
├─ Flower.pde  Seed.pde  Petal.pde      꽃 한살이 · 씨앗 · 흩날리는 꽃잎
├─ Soil.pde  Butterfly.pde  Vine.pde    거름 · 나비와 꽃가루 · 덩굴
├─ Meadow.pde                           3D 잔디 평원 (P3D, 기본 카메라 = 웹캠 좌표)
├─ Sound.pde  Gui.pde                   소리(Minim) · 조절판(ControlP5)
└─ data/                                소리 5개 (임시 합성음)
visionTest/                             웹캠 입력만 따로 시험하는 스케치
```

## 진행 상황 (2026-11-11)

- **정원(B):** 거의 완성 — 한살이 · 씨앗 · 흩날림 · 햇빛 · 하늘 · 거름 · 나비 · 덩굴 · 산들바람 · 소리 · 조절판 · 만개 · 안내 문구
- **입력(A):** 웹캠 · 배경 빼기 · 칸별 움직임 · 실루엣 · 가장자리 점 · 기록 장치까지
- **남은 일:** 웹캠 측정 실험 → 실루엣으로 자세·손 흔들기·기울기 판정 → 실제 몸으로 숫자 맞추기 → 리허설·발표
- 소리 파일(`data/`)은 사인파로 합성한 **임시 음원**이다. 같은 이름으로 바꿔 넣으면 된다.
- 코드는 두 사람이 Claude(AI)와 함께 작성했다. 진행 메모에 날짜·담당별로 기록한다.
